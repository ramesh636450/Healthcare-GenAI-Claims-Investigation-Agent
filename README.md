# Healthcare GenAI Claims Investigation AI Agent


## Project Overview

An AI-powered healthcare claims investigation system using Generative AI and Retrieval Augmented Generation (RAG).

The application analyzes healthcare claims, retrieves relevant insurance guidelines, and generates automated audit reports including fraud risk, denial risk, findings, and recommendations.


## Features

- Healthcare document knowledge base
- RAG architecture using Chroma Vector Database
- OpenAI LLM integration
- Claim investigation automation
- Fraud risk analysis
- Denial reason analysis
- Streamlit web interface


## Technologies Used

- Python
- Generative AI
- OpenAI API
- LangChain
- ChromaDB
- RAG
- Streamlit
- Pandas
- Excel
